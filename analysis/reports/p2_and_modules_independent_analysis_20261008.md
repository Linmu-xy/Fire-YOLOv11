# P2、SRDG、DCBR、ACR 独立诊断

日期：2026-10-08。分析对象：已完成的 D-Fire 协议实验，以及旧 FASDD 跨域报告、FireSmoke-YOLO 和新 FASDD clean 的数据构成。读取了历史 checkpoint 的 CPU 参数、训练曲线、Git 历史来源和清单/图像头信息；没有模型前向、新推理、训练或单元测试。

## 核心判断

对 P2 小幅收益，目前有两条较直接的证据和一项未验证的结构因素：

1. **收益主要出现在火焰，烟雾多数较大，主要困难涉及外观/背景和定位。** 当前 P2 及附加模块只显式改造 P2 前向分支，对大尺度分支没有新增的特征反馈。
2. **小目标本身的增益也不大。** 历史尺寸分层没有显示从低 AP 到高 AP 的跃升，增加采样位置并没有充分解决微小火焰的可辨识性与定位。
3. **实际结构同时增加了高分辨率分支，并缩窄了原有三个分类分支。** checkpoint 已确认这个变化，但**没有证据证实通道缩窄使准确度变差，或抵消了 P2 收益**。此前将它排为高优先级病因的措辞过重。

三个附加模块均分别接在 P2 上，历史实验不是 SRDG→DCBR→ACR 依次叠加。以下分别解释各自机制、结果与局限。

![数据集与模块独立对照](../artifacts/historical_diagnosis_20261008/p2_module_diagnosis.png)

## 1. 证据与对照有效性

- baseline/P2 都是 100 epoch、640、batch32、SGD、lr0=.01、AMP=false、共同预训练共享层 0..22、检测头重新初始化。
- baseline/P2 的六个运行 portable 清单/标签指纹均为 `033e970451ffc052cf13f66113bb65dfc48e82c3984f89a0a73e0a34f8bbaf29`，train/val/test 均为 15485/1722/4294。此历史指纹不含图像内容。
- 恢复了记录的 8 种源码哈希并逐一对应到 Git 文件。`models.py` 差异主要是新增模块、导入和架构分派；共享权重迁移、训练预处理与背景损失路径没有相应改变。`data.py` 差异是 v2 协议支持、prepare 阶段可选负图重复及元数据字段。该 D-Fire 对照没有启用负图重复，清单指纹和样本数一致。
- 因此，上一轮“源码哈希不同，需要核对”的疑点已得到更具体解释：**已恢复文件未发现改变这些父级对照的训练行为。** 不能仅凭哈希不同就把实验判为不可比较。
- 主要曲线有限、完成 100 轮；当前 FASDD clean seed0 不包含在历史模块结果中。旧遗留 `optimizer=auto` 等运行不混入当前同协议表。
- 所有验证数字取各自最佳 mAP50-95 的同一行；它们是验证选择后的结果，不是独立测试收益。

## 2. 数据集独立分析

### 2.1 尺寸口径

本次逐图读取尺寸与 canonical 框，按保持纵横比、整图最长边缩放到 640 计算。统计是**静态数据几何**，不含 Mosaic、随机缩放和实际验证 rect/scaleup 差异，不称作 COCO AP-small。另计算短边与面积平方根，避免仅长边掩盖细长框。

| 训练集 | 图像数 | 火焰框数 | 火焰长边<16px | 烟雾框数 | 烟雾长边<16px | 烟雾长边≥64px |
|---|---:|---:|---:|---:|---:|---:|
| D-Fire | 15,485 | 10,633 | 1,195 / **11.24%** | 8,564 | 119 / 1.39% | 78.65% |
| FASDD 原版 | 47,658 | 39,528 | 2,219 / **5.61%** | 27,035 | 10 / 0.037% | 96.23% |
| FASDD clean v1 | 44,113 | 33,137 | 1,291 / **3.90%** | 22,869 | 6 / 0.026% | 96.74% |
| FireSmoke-YOLO | 6,616 | 7,216 | 31 / **0.43%** | 5,303 | 0 / 0% | 98.89% |

按缩放后 `sqrt(width×height)<16px`，火焰比例分别为 **17.23%、9.16%、6.50%、0.91%**；烟雾分别为 2.24%、0.118%、0.061%、0%。按短边<8px，D-Fire 火焰为 5.36%，clean FASDD 为 1.39%。换口径之后，小火焰相对集中于 D-Fire 的判断仍成立。

**D-Fire：**有足够的小火焰值得研究 P2，但它也有大量中大火焰、烟雾和背景。验证集 8–16px 火焰 95 个，烟雾只有 8 个；单个微小烟雾尺寸档不足以给可靠机制结论。

**FASDD：**数据量和来源覆盖增加，但烟雾几乎都是较大目标，小火焰比例低于 D-Fire。删重还将 train 的 <16px 火焰框从 2,219 减至 1,291，尺寸分布发生了变化。因此，换成 FASDD 后整体效果可能改善，P2 的相对增益却不一定扩大。16–32px、细长目标等仍可能受益，不能据此断言 P2 无效。

**FireSmoke-YOLO：**极小目标更少，不能把它当作主要验证 P2 极小目标机制的数据集。只有 baseline 训练结果，没有它的 P2/模块对照；其低 baseline 分数不能作为 P2 失败证据。此外，火烟同时存在的图像占全部图像比例为 train **38.75%**、val **48.17%**、test **72.85%**；仅烟比例为 21.39%、7.05%、1.90%。切分构成差异值得重审，但它不是已证实的过拟合因果解释。

背景比例 D-Fire 为 45.48%，clean FASDD 为 44.26%；火/烟框数量也没有极端数量失衡。当前问题不能简单归结为“没有足够负图”或“烟雾框太少”。

## 3. P2 独立分析

### 3.1 当前图结构

原 backbone/neck 0..22 保留。新增路径为：

```text
P3(layer16, 64ch, stride8) → nearest ×2 ┐
backbone P2(layer2, 64ch, stride4) ──────┴→ Concat128
  → DWConv128 → Conv1×1 32ch → C3k2 32ch → P2 Detect

Detect 输入：[P2 32ch, P3 64ch, P4 128ch, P5 256ch]
```

这条路径显式保留更多空间位置，但 P2 输出被压缩到 32 通道。改后的 P2 不再下采样送回 P3/P4/P5；那些显式前向路径保持原图。共享 backbone 的训练梯度仍可改变各层，不能说其它层完全不受影响。

### 3.2 已确认的结构混杂：所有分类分支变窄

安装版本的 Detect 使用 `c3=max(ch[0], min(nc,100))`。两类任务下：

| 项目 | baseline | 当前 P2 |
|---|---|---|
| Detect 输入通道 | 64/128/256 | 32/64/128/256 |
| 各分类分支中间宽度 | **64/64/64** | **32/32/32/32** |
| 框回归中间宽度 | 64 | 64 |
| 总参数 | 2,590,230 | 2,638,312 |
| 原 P3/P4/P5 分类卷积权重数（不含 BN/偏置） | 47,104 | 22,496 |

历史 best.pt 的实际卷积形状确认了这点。原有三路分类卷积权重数减少 **52.24%**；总参数却只增 **1.86%**。上游公式参见 [Ultralytics v8.4.42 Detect](https://github.com/ultralytics/ultralytics/blob/v8.4.42/ultralytics/nn/modules/head.py)。

**判断：**这次 baseline→P2 实验测的是“增加 P2 + 改变分类头容量”的净效果。分类变窄是否影响精度、影响方向与幅度均未知。两类分类任务可能32通道已足够，较少通道也可能改善泛化；仅凭参数量无法判定。模块相对父级 P2 的比较共有相同的32通道分类头，它不能直接解释这些模块间的差异。

### 3.2.1 对“通道导致小幅收益”的反证检查

又逐一查看了三个 seed 的 best.pt 历史 PR 图。图例中的 D-Fire val **AP50** 约数（图例只保留三位小数）如下：

| seed | fire baseline→P2 | smoke baseline→P2 |
|---|---:|---:|
| 0 | .735→.747 | .857→.860 |
| 1 | .739→.747 | .853→.858 |
| 2 | .740→.732 | .846→.855 |

烟雾三 seed 都略升，火焰两个升、一个降；总体 mAP50-95 三 seed 全部略升。seed0 混淆矩阵的火焰匹配检出 **815→846**，烟雾 **806→803**；按该图生成时的工作点，直接火/烟交叉误分基本不变（fire GT→smoke 为6，smoke GT→fire 为2）。混淆矩阵的背景列是误检框数，不能解释成背景图告警率。

这些现象**没有显示分类头缩窄造成明确的分类性能退化**。它们同样不能证明通道无影响，因为新增 P2 与通道变化同时发生，且 AP50 无法单独反映高 IoU 定位。现有资料无法给通道因素分配任何可信的“损失了多少百分点”。

### 3.3 额外网格不等于额外有效监督

640 方形输入的候选位置由 `80²+40²+20²=8400` 增至 `160²+8400=34000`，约 4.05 倍。当前检测损失仍使用每 GT 的 top-K=10 task-aligned 分配，跨全部层竞争，由分类分数和 IoU 共同决定。

所以多出 25,600 个候选，并没有把每个 GT 的正样本预算同时增加四倍；很多新增位置仍提供负例分类梯度。是否让小火焰更多分配到 P2，现有日志没有统计，尚不能确认。

该版本也对小于最小 stride 的框扩大候选搜索范围：baseline 最小 stride8，相关维度可扩到16；P2 最小 stride4，可扩到8。因此，原脚本“目标不足一格就完全看不到”“P2 唯一作用域是8–16px”的说法过强。参考 [v8.4.42 TaskAlignedAssigner](https://github.com/ultralytics/ultralytics/blob/v8.4.42/ultralytics/utils/tal.py)。

### 3.4 大烟雾与 P2 的作用范围

当前 DFL 使用 16 个距离 bin（0..15）；stride4 的单侧距离不超过约 60 输入像素，预测宽/高上界约 **120px**。这限制了 P2 单独精确覆盖大烟雾框的范围，不代表它对大框绝无 AP50 命中可能；大烟雾的完整定位仍需要 P3/P4/P5。公式来自当前 DFL 解码，参见 [v8.4.42 DFL](https://github.com/ultralytics/ultralytics/blob/v8.4.42/ultralytics/nn/modules/block.py)。

D-Fire train 烟雾缩放后长边中位数为 **240px**；clean FASDD 为 **216.5px**。同时，旧 P2 跨域尺寸分析中 ≥64px 烟雾 AP50-95 从 56.10% 降到 23.99%。这说明当前大幅漏烟问题超出了仅提高细网格分辨率能够保证解决的范围。

### 3.5 实际增益发生在哪里

| 同 seed 最佳验证 mAP50-95 | baseline | P2 | 变化 |
|---|---:|---:|---:|
| seed0 | 47.706% | 48.384% | +0.678pp |
| seed1 | 47.307% | 47.708% | +0.401pp |
| seed2 | 46.929% | 47.609% | +0.680pp |

三个 seed 都提高，平均 **+0.586pp**，是小幅一致的观测收益。三 seed 不能给强统计结论，也不该把它称为“完全没有用”。

旧自定义 D-Fire val 尺寸分层 AP50-95：

| 尺寸档 | 火焰 baseline→P2 | 变化 | 烟雾 baseline→P2 | 变化 |
|---|---:|---:|---:|---:|
| <8px | 0.546%→0.276% | −0.270pp | 样本仅1个 | — |
| 8–16px | 1.990%→2.669% | +0.679pp | 0.564%→0.584% | +0.020pp |
| 16–32px | 15.070%→16.033% | +0.963pp | 8.524%→8.008% | −0.516pp |
| ≥32px | 45.668%→46.727% | +1.059pp | 54.491%→54.589% | +0.098pp |

火焰的提升跨多个尺寸档，不能仅归因于新增小目标层；微小火焰绝对 AP 仍很低，烟雾基本没有稳定明显提升。表为历史自定义评估，口径限制见第7节。

旧 FASDD test：baseline→P2 seed0 总 mAP50-95 **34.06%→34.75%**；fire AP **44.47%→45.37%**，smoke AP **23.66%→24.13%**。共享阈值下背景告警 **9.81%→9.67%**，仅烟告警召回 **32.6%→33.9%**，核心问题仍在。

历史 profiler 估算 FLOPs@640 为 **6.4417→10.1378G，约+57.4%**，参数只增1.86%。这是工具估算，不能当作实测延迟。额外计算主要花在高分辨率处理上，语义容量增幅有限。

同 seed baseline800 最佳验证48.311%，当前 P2@640为48.384%，只差0.073pp。按分辨率平方近似，baseline800计算约10.07G，与P2@640接近；这只是预算对照线索，未做同硬件推理测量，不能据此宣布两者等价。

**P2 独立结论：**方向上有小幅收益。小火焰虽有一些改善，绝对AP仍低；多数烟雾尺度和跨域错误并非当前P2分支直接针对的问题。分类头缩窄是已确认的实验混杂因素，**不是已确认的低收益原因**。

## 4. SRDG 独立分析

### 机制

`D'=D×[1+0.5×tanh(Conv1×1(S))]`。仅依据 P3 上采样语义 S 调制浅层 D，乘数范围0.5..1.5，参数增加4,160。

- S 用 nearest 上采样，1×1门控在同一原P3格对应的2×2 P2位置上相同，无法根据这些位置不同的细节 D 作不同决策。
- 只做特征缩放，没有生成新的细节或目标级分类证据；现有 P2 后续卷积本来已经融合 S、D，新增门控可能只带有限额外能力。
- 粗语义不足时，门控可能连弱目标证据一起调制；这是机制解释候选，需要真实特征/失败样本验证。

### 结果

seed0 最佳验证 AP50-95 **48.098%**，相对P2 **−0.286pp**。同一最佳行 P 上升3.678pp、R下降2.940pp，但验证器工作点可能不同，不能据此证明同阈值抑制误报。

旧目标 test：mAP **34.33%**，相对P2 **−0.42pp**；共享阈值背景告警 **10.13%**，高于P2的9.67%；仅烟召回36.2%，高于P2的33.9%。表现是指标之间的取舍，未显示整体稳定改善。

checkpoint 中零初始化输出投影已非零，权重RMS约0.0408，排除了“参数一直没学习”的简单解释。没有激活探针，不能判断门控饱和或弱烟被抑制。

**SRDG 结论：**当前粗语义逐点门控的信息输入和表达范围较受限，单seed未证明目标域误报改善。下一步优先核对门控在真实TP/FN/背景FP区域的差异，而非直接叠更多模块。

## 5. DCBR 独立分析

### 机制

`L=Avg5(Avg3(D))`，`M=Avg3(D)-L`，`H=D-Avg3(D)`；根据 `[S,L,abs(M)+abs(H)]` 产生门控，输出 `D'=D+gM×M+gH×H`。hidden16、8组，每组8个细节通道共享门控，门控范围±0.25，增加3,520参数。

- 这是空间平滑残差分解，没有FFT或正交频带，也没有监督保证高频等于火、低频等于烟。
- 低频 L 直通有利于避免整体削弱，但弥散低对比烟雾的 M/H 可能弱，能改动的部分也可能有限。
- 灯光、花瓣、树叶同样可以有强细节残差；是否增强目标或背景，仍取决于训练条件与监督。
- `semantic` 和 `whole` 已有配置，但未找到完成的消融训练结果，无法独立证明局部条件/分带设计的必要性。

### 结果

seed0 验证相对P2 **−0.224pp**，seed2 **+0.468pp**，平均+0.122pp。方向相反，不能认定稳定收益。

旧目标 test 的相对P2变化分别 **−0.44pp、+0.57pp**；共享阈值背景告警分别12.32%、9.51%，相对各自P2为+2.65pp、−0.78pp；仅烟召回39.0%、29.9%，相对各自P2为+5.1pp、−4.3pp。优劣随seed变化。

投影权重均已非零；seed0权重RMS约0.0528，seed2约0.00655。参数状态差异提示两次训练走到不同解，但权重RMS不能替代门控输出或残差相对幅度，不能据此断言seed0过强、seed2过弱。

**DCBR 结论：**比SRDG多了局部条件与受限分带残差，但现有数据无法证明这两个机制稳定有效。优先看实际残差在目标/背景上的作用，并完成有明确判别目的的内部消融。

## 6. ACR 独立分析

### 机制

P2位置上的九个邻域平移候选对 S 做凸组合；D压至16通道，经 dilation1/3/5 的三路深度卷积与softmax路由；输出 `[S+Ws(A-S), D+Wd(E)]`，增加8,908参数。

- 对齐只能局部移动一格，即stride4下名义±4输入像素，不能恢复在stride8语义中已经丢失的细节，也不能解决任意尺度错位。
- 三路卷积核的名义采样范围为3/7/11个P2格，即12/28/44输入像素。上游特征已有更大感受野，不能将这些数值称作模型总感受野；它们也不是已被监督定义的火/烟专家。
- 模块只显式作用在新增P2路径；大量大烟雾主要需要较粗检测层，局部P2修正未覆盖这些层的直接融合问题。
- 零投影保证起点恒等，输出投影打开后内部路由再获得梯度；checkpoint 已非零，不支持“始终没打开”的解释。
- 与DCBR不同，输出自由残差没有25%幅度界；是否引入过强背景响应仍需激活证据。

### 结果

seed0最佳验证 **47.854%**，相对P2 **−0.530pp**；曲线后期平台，没有明显训练发散。

旧目标 test mAP **35.35%**，相对P2 **+0.60pp**；smoke AP **25.39%**，相对P2 **+1.26pp**。然而共享阈值背景告警 **10.68%**（P2 9.67%），仅烟召回 **32.3%**（P2 33.9%）。目标AP与固定告警工作点的表现不同，不能用其中一个掩盖另一个。

semantic_out/detail_out 权重RMS约0.0529/0.00399；维度、输入与分支不同，不能直接比较它们的实际贡献。未找到 `no_align/uniform/local` 完成运行，因此不能归因“对齐有效”或“路由无效”。

**ACR 结论：**有单seed跨域烟雾AP改善线索，值得保留，但没有稳定增益或低误报证据。优先拆开对齐、路由和多尺度上下文的贡献，并检查作用层级是否与大烟雾错误对应。

## 7. 其它干预与评估边界

### 背景损失、风格增强和负图重复

配置中另有 `background/p2_background/full`，但这些不属于已完成模块表。上述P2/SRDG/DCBR/ACR运行均为background_alpha=0、style=false，不能把结果解释为这些干预的效果。

背景损失只对增强后无GT的图像，按类别惩罚top32 logits；正图中的难负区域仍主要由原损失处理。历史D-Fire seed0日志：前10轮增强后空图约 **22.21%**，最后10轮关闭Mosaic后约 **46.45%**。原始45.48%背景比例不等于每轮纯背景曝光比例；正图依然包含负例位置，不能据此说背景没有学习。

风格增强是gamma、对比度与少量灰度扰动，不会自动增加花朵/灯光/云雾等语义困难负样本。负图重复改变曝光，不增加新的场景信息；尚无完成结果证明它们改善本项目。

### 历史尺寸评估的具体问题

本报告使用旧 `long_lb` 表作为诊断线索，不能冒充严格COCO AP-small：

1. `stratified_ap.py` 的 `coco_area` 路径用了**长边平方**，不是width×height；如果使用该路径，会把细长框错误分档。当前引用的表使用long_lb，不受该面积变量错误直接影响。
2. 匹配实现是自定义贪心，未完整实现COCO有效GT优先和未匹配检测面积忽略等逻辑；该表的精确AP与官方口径可能不同。
3. `voc_ap_101` 实际是PR包络阶梯积分，名字与标准101点采样不一致。不要把自定义分层AP数值直接拼入官方总体AP表。
4. 8–16px不是P2唯一有效区间，框数占比也不能线性换算整体AP收益上限。

旧跨域目标结果来自已保存预测，权重/缓存绑定还需在正式统一重评时固定。共享阈值仅用于同一数值阈值下的行为观察，不等于每个模型处于相同实际FPR。旧zero-shot表源域箭头数据复用错误、本报告未使用；旧MDD计算不用于显著性判断。

数据精确重复及同场景依赖仍影响外部结论。旧测试集已用于诊断设计，本文目标test表是探索性证据，不是新的盲测结果。

## 8. 建议的优先顺序

1. **保持当前 FASDD clean baseline seed0，先建立新数据的基线。** 新数据规模增大、小目标占比却降低，不能预设P2一定涨更多。
2. **需要判定通道因素时做严格对照。** 保持P2特征输入32通道、回归头与所有训练设置一致，只将`Detect.cv3`的中间宽度由32固定为64；与原P2在同样seed上配对。为了进一步分离“有无P2”与“分类宽度”，可形成baseline/P2 × 分类宽度32/64的2×2设计。仅将P2输出也扩大为64会同时改变特征容量，无法单独回答通道问题。报告分类别AP、目标尺寸、成本及告警表现；当前没有运行此对照。
3. **统一尺寸评估实现。** 修正面积口径并对齐官方匹配规则；按长边、短边/面积、类别分别看召回和定位，记录预测来自哪个stride。
4. **补正样本分配/特征诊断。** 对训练/验证样本按小火TP/FN、大烟FN、背景FP分组，看P2是否获得有效正样本，以及门控/残差是否作用于真正错误位置。整图平均门控不能证明机制。
5. **模块分别消融，避免同时更改数据和多个机制。** SRDG看粗语义门控与弱目标取舍；DCBR对比semantic/whole；ACR对比no_align/uniform/local及普通卷积残差。先用验证证据决定是否投入更多seed。
6. **烟雾与背景问题采用与错误对应的干预。** 复核漏标/框边界、增加训练/验证来源中的困难负样本与烟雾外观覆盖；如果错误主要属于较大烟雾，研究P3/P4等层级的作用，而非只改P2。
7. **在统一验证校准下比较告警质量。** 每模型独立校准并冻结阈值，再报告目标告警召回/误报，同时保留AP；后续冻结实验需场景独立的确认性评估。

这些是后续实验建议。本次只保存独立分析、读数与脚本，没有改模型、旧评估代码或当前训练。
