# 历史训练效果诊断

日期：2026-10-08。依据：15 份历史 `run.json/results.csv`（含一份 55 轮备份）、已有预测分析报告、数据审计，以及四张历史高分误报原图。本次没有新训练或新模型推理。

## 结论

现有证据最支持：**跨数据集的烟雾泛化不足、背景与火烟的语义混淆，是当前主要短板。** D-Fire 的结构改进收益较小，后期提升放缓；FireSmoke-YOLO 另有明显的过拟合迹象。数据泄漏和评估脚本问题影响结论可靠性，但不能直接用来解释低分。

目前正在运行的 `fasdd_cv_clean_v1` baseline seed0 不在本报告的历史统计中。这次分析没有修改它的训练设置。

## 1. 先明确“效果不好”指哪一种指标

| 历史运行 | 最佳验证 mAP50-95 | 最佳轮数 | 最后记录的 mAP50-95 |
|---|---:|---:|---:|
| D-Fire baseline seed0 | 47.706% | 99 | 47.702% |
| D-Fire P2 seed0 | 48.384% | 100 | 48.384% |
| D-Fire P2 + SRDG seed0 | 48.098% | 94 | 48.041% |
| D-Fire P2 + DCBR seed0 | 48.160% | 78 | 48.071% |
| D-Fire P2 + ACR seed0 | 47.854% | 73 | 47.679% |
| FireSmoke-YOLO baseline seed0 | 20.115% | 55 | 16.936% |

D-Fire baseline seed0 的最佳验证 mAP50 为 79.605%，但 mAP50-95 为 47.706%。后者对多个 IoU 阈值取平均，要求更严格的框定位；这些 AP 数字不能称作“识别准确率”。定义参见 [Ultralytics 指标文档](https://docs.ultralytics.com/guides/yolo-performance-metrics/)。这个差距提示需要进一步看定位误差与目标尺寸，不能据此断言标注错误。

## 2. 最有证据的短板：烟雾跨域泛化

D-Fire baseline seed0 的历史 FASDD test mAP50-95 为 **34.06%**；D-Fire 最佳验证值为 47.706%，两者相差 13.646 个百分点。验证集与目标测试集难度不同，因此这个差值是跨域表现差异，不能全部归因于某一个因素。

目标 FASDD 的分类别 AP50-95：

- fire：44.47%；
- smoke：23.66%。

历史共享阈值下，baseline 在仅烟图像上的图像级告警召回，从 D-Fire val 的 **62.6%** 降至 FASDD test 的 **32.6%**；火烟同时存在图像的烟雾召回从 77.4% 降至 53.2%。P2 的对应仅烟召回为 62.8% → 33.9%，没有消除这个问题。

这些是“图像中是否出现超过阈值的该类预测”的召回，没有要求预测框与 GT 匹配，不能当作检测框召回。

尺寸分层进一步说明：P2 在长边 ≥64px 的烟雾上，D-Fire val AP50-95 为 **56.10%**，FASDD test 为 **23.99%**。FASDD test 的烟雾框有 **96.6%** 落在这个尺寸档，尺寸按 640 输入 letterbox 后计算。因此，大量跨域漏烟不能仅用微小目标分辨率不足解释。

**判断：**烟雾外观、场景和背景的变化，是比继续增加细节检测模块更值得优先处理的方向。烟雾轮廓模糊及标注边界差异也可能影响定位，但目前尚未完成逐框标注复核，不能把它们定为已证实原因。

“有火时烟更容易检出”存在，但两组烟雾尺寸分布不同；这不足以证明模型因果上依赖火焰。

## 3. 高分背景误报：代表性不足与颜色/纹理混淆

旧 FASDD test 的 6,533 张背景图中，baseline 有 **641 张触发任意火/烟告警，比例 9.81%**。其中仅火触发 472 张、仅烟 149 张、两类同时触发 20 张。包含火告警的 492 张占全部误报图的 76.8%。

阈值为 fire=0.3143、smoke=0.6057，来自 P2 seed0 的 D-Fire val 校准。它们被历史分析共享使用，不能说每个模型都独立校准到了 1% FPR；目标域任意告警率也不同于源域单类别 FPR。

我查看了以下四张原图，历史预测分数如下：

| 背景图 ID | fire 最大分数 | smoke 最大分数 | 原图可见内容 |
|---|---:|---:|---|
| CV001265 | 0.932 | 0.002 | 暖光下的头发、人物与话筒/乐器 |
| CV014005 | 0.061 | 0.896 | 盆栽、浅色虚化背景 |
| CV012573 | 0.862 | 0.003 | 红橙色花朵/植物 |
| CV021881 | 0.857 | 0.378 | 橙色花朵与绿叶 |

![历史高分背景误报原图](../artifacts/historical_diagnosis_20261008/historical_false_alarm_examples.png)

这是按高分挑选的四例，支持颜色/纹理混淆的怀疑。图中没有叠加预测框，所以不能断定预测具体落在头发、花瓣或背景上，也不能据四例推断全部误报的成因。

D-Fire train 15,485 张中有 7,043 张背景，比例 **45.48%**；背景数量并不少。更合理的疑点是训练背景对目标场景中的易混淆内容覆盖不足。简单重复普通背景，未必能改善这些高分误报。

## 4. 结构模块的收益，与主要问题不完全对应

baseline → P2 的三个 seed 最佳验证 mAP50-95 分别提高 **0.678、0.401、0.680 个百分点**，平均约 **0.586 个百分点**。方向一致，但增益较小。

新增模块应与其父模型 P2 比较：

| 模块 | seed | 相对同 seed P2 的变化 |
|---|---:|---:|
| SRDG | 0 | −0.286 个百分点 |
| DCBR | 0 | −0.224 个百分点 |
| DCBR | 2 | +0.468 个百分点 |
| ACR | 0 | −0.530 个百分点 |

DCBR 在两个 seed 上方向相反。其余模块仅有一个 seed，不能下“永远无效”的结论，但现有结果不支持它们稳定解决主要短板。

后续独立分析已从 Git 恢复不同哈希的源码：差异主要是新增模块注册、协议支持和未启用的 prepare 负图重复，未发现这些对照的共享训练逻辑实质改变。另发现 P2 使全部分类分支从 64 通道缩到 32，详见 [P2 与模块独立分析](p2_and_modules_independent_analysis_20261008.md)。上述数字仍是当前结构净变化的观测值，不能将它们归因于单一机制。

提高分辨率的 seed0 最佳验证值：640 为 47.706%、800 为 48.311%、960 为 48.912%、1280 为 45.011%。1280 正式运行已经完成 100 轮；55 轮文件是备份。1280 的 batch=16，其余为 32，因而不能把退步完全归因于分辨率。800 曲线缺第 8、9 轮记录。

**判断：**现有 P2 提升有限；继续堆叠模块或提升输入尺寸，尚缺少能解决跨域烟雾和语义误报的证据。

## 5. D-Fire 提升放缓；FireSmoke-YOLO 有过拟合迹象

### D-Fire

主要运行完成 100 轮。所读取的 15 份曲线没有 NaN/Inf 数值，也没有明显的训练发散。

baseline seed0 验证 mAP50-95 的窗口均值：20–30 轮为 41.356%，45–55 轮为 46.327%，80–89 轮为 47.410%，91–100 轮为 47.611%。后期收益明显变慢。

这说明当前配方在记录预算内接近平台，不能证明更多轮数绝无收益。最后十轮关闭 Mosaic 会改变训练难度，不能把此阶段训练损失下降单独当作过拟合证据。

### FireSmoke-YOLO

最佳验证 mAP50-95 在第 55 轮为 **20.115%**，第 100 轮降至 **16.936%**，下降 3.179 个百分点。

第 55 → 100 轮：训练 box loss 从 **1.771 降到 1.536**，验证 box loss 从 **2.074 升到 2.333**；训练分类损失也继续下降。训练与验证定位损失的差距在关闭 Mosaic 前已经扩大。

这是更强的过拟合信号：模型继续适应训练集，而验证表现变差。该数据集训练图仅 6,616 张，场景覆盖、标注一致性和切分代表性值得复核，但数量较小本身不能证明低分原因，因为不同数据集任务难度不同。

历史协议使用共同预训练权重的可迁移层，并重新初始化检测头；不能把这些运行理解成“已有完整 D-Fire 检测器继续微调”。这个初始化是登记过的实验设计，尚无对照证明它是低分原因。

## 6. 数据与评估问题影响可信度

- 发现 FASDD 与 D-Fire 字节相同的图像 5,733 张，其中 D-Fire train 与旧 FASDD test 重合 277 张。反方向 FASDD train 与 D-Fire test 重合 649 张。泄漏通常可能使成绩偏乐观，不能直接解释低分，也不能量化删重后分数将如何变化。
- 新版本清除了已确认的跨数据集、跨 split 精确重复与非法标签，最终 89,405 张，train 44,113 张，约为 D-Fire train 的 2.85 倍。训练背景占 44.26%，与 D-Fire 相近。增加规模和来源覆盖有改善潜力，目前没有新版本训练结果可以确认。
- 168,098 对感知相似候选只是审计线索，不能全称为泄漏；同场景/连续帧独立性仍需审查。旧 test 已用于开发诊断，不能当作全新盲测集。
- 旧 `zeroshot_eval.py` 的部分源域告警统计复用了阈值来源模型的预测，跨模型的源域表不能直接采信。本报告的按图像类别召回来自逐模型读取预测的另一份分析；目标侧数字是历史结果，缓存来源仍需要在正式重评时绑定权重与数据指纹。
- 共享阈值没有给所有模型提供相同的实际 FPR。正式告警比较应在各自验证集独立校准，再冻结阈值比较目标表现。
- 旧统计报告将置信区间半宽当作 MDD，不能据此声称模块在统计上不可能有效；AP 也不能按框数量简单线性加权来证明小目标改进的理论上限。
- 两台主机当前核心训练代码、公共模型配置和历史结果一致，没有证据指向 cmj 的核心项目落后导致低分。D-Fire 有 11 张 test JPEG 内容差异，需要固定数据版本以保证严格复现；目前不能把大幅跨域下降归因于这 11 张。
- 标签已规范为 0=fire、1=smoke，并处理 D-Fire 原始类别顺序；没有发现类别颠倒证据。

## 7. 下一步优先级

1. **完成当前 FASDD clean baseline seed0**，用验证集观察分类别 AP、仅烟场景表现与背景误报；先确认换数据后的基线改善幅度。
2. **从训练/验证集抽取误报、漏烟、定位错误样本复核**，按花朵/灯光/夕阳、云雾/蒸汽、远距离淡烟、标注漏框等具体类别记录。困难负样本必须确认确实没有目标；不要直接把旧测试图添加进训练集后仍称其为测试集。
3. **固定代码、数据、初始化和评估流程，再补配对 seed**。模块的零点几百分点收益需要与随机性和代码变更区分。
4. **逐模型做验证集阈值校准**，同时报告检测 AP、固定误报约束下的图像级告警召回。单一 mAP 不能完整描述告警系统效果。
5. **再选择针对性对照**：更大模型、烟雾场景采样、困难负样本或正则化，每次改变一个因素。FireSmoke-YOLO 如继续使用，优先复核数据并保存最佳验证权重，研究早停/正则化；不能把最后一轮当成最佳模型。

以上是后续实验建议；本次未启动这些训练或评估，也没有改变正在进行的 seed0。
