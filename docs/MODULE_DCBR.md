# DCBR：细节条件化频带残差候选

设计日期：2026-09-19。依据仓库 `940a963` 的已归档结果设计；尚未训练。
目标是提出可检验的机制并提供可运行实现，不承诺精度增长、首次提出或期刊分区。
文献检索与近邻方法比较见 [RESEARCH_DCBR.md](RESEARCH_DCBR.md)。

## 1. 已有证据及修正

从各运行 `results.csv` 选择 **同一行最高 validation mAP50-95**，不拼接其他 epoch 的 P/R：

| 方法 | seed | epoch | P | R | mAP50 | mAP50-95 |
|---|---:|---:|---:|---:|---:|---:|
| P2 | 0 | 100 | 0.78426 | 0.74535 | 0.80345 | 0.48384 |
| P2 | 1 | 94 | 0.78791 | 0.73400 | 0.80206 | 0.47708 |
| P2 | 2 | 95 | 0.79753 | 0.71573 | 0.79358 | 0.47609 |
| P2+SRDG | 0 | 94 | 0.82104 | 0.71595 | 0.79863 | 0.48098 |

P2 mAP50-95 为 `0.47900 ± 0.00422`（n=3，样本标准差）。SRDG 的配对 seed0 变化：
AP50-95 -0.286 个百分点、AP50 -0.482 个百分点、P +3.678 个百分点、R -2.940 个百分点。
这不足以证明 SRDG 可靠提高误报抑制，也不证明门控导致真实弱目标被抑制；后者只是待验证解释。

需要纠正前次分析中的几个推断：

- `D-Fire_seed*` 是历史 `optimizer=auto/amp=true/整模型预训练` 运行，与协议 P2 不是受控对照。
  历史均值差不能证明 P2 的结构贡献。用户已在另一台电脑跑过 baseline，本轮不安排重复训练；
  后续接收同协议结果时核对 `run.json`、数据指纹与初始化策略。
- CSV 的 P/R 是验证器选择工作点后的汇总值；不同模型的工作点可以不同。P 提高不能直接推出
  固定召回率下 FP 减少，R 降低也不能直接量化同阈值漏检增幅。
- 归一化混淆矩阵的 background 列是 FP 的类别构成，不是背景图报警率。
- PR 图只支持约数：fire AP50 从约 .747 到 .737，smoke 约 .860 到 .859。最终验证可能与 CSV
  因 checkpoint 精度、重新验证等有微差；精确类别结论需统一重评 best.pt。
- 训练总时长来自不同运行环境，`12089.2/11388.4-1≈6.15%` 只是观测值，不是受控速度增幅。
- 调整置信度阈值能改变 P/R，不能凭阈值扫描把较低的完整 PR 积分 AP 变成结构增益。
- 高分辨率 P2 并不自动等于小目标 AP 改善；目前尚缺尺寸分层证据。

## 2. 研究假设

SRDG 使用 `D'=D*(1+0.5*tanh(W*S))`，仅以粗语义控制整张浅层特征。
假设：粗语义对小火焰和薄烟证据不充分时，整特征调制可能同时改变有用局部细节和背景纹理。
DCBR 将调制范围限制为两组细节残差，并让门控也观察浅层局部信息。

这不是“所有火焰都是高频、所有烟雾都是低频”的分类假设。
SET 等工作表明，小目标在编码后的频谱和原始图像纹理不能简单等同；本模块允许增强和抑制，
并保留粗尺度成分的直接通路。是否改善召回、误报、定位，必须分别评价。

## 3. 精确定义

在与 SRDG 相同位置插入：P3 上采样（64 通道）与 backbone P2（64 通道）Concat 之后，
原 P2 DWConv 之前。共享层 0..22、P2 后处理结构及四尺度 Detect 都保留。

`S` 为上采样语义，`D` 为浅层细节，`A_k` 为 stride=1 的 k×k 平均池化：

```text
U = A3(D)
L = A5(U)
M = U - L
H = D - U                     # D = L + M + H
E = abs(M) + abs(H)
C = SiLU(DWConv3(SiLU(Conv1(Concat(S, L, E)))))
[aM, aH] = 0.25 * tanh(Conv1_zero(C))
D' = D + aM * M + aH * H
Y = Concat(S, D')
```

隐藏通道 16，8 个通道组；每个 gate 的组系数在组内共享。所有卷积均有 bias，无额外 BN。
两层池化都不计入 padding 零值，因此空间常量在边缘处也保持常量。

数学与实现边界：

1. 这是局部平滑残差分解，具有低通及带通倾向；不是正交小波、FFT 或严格互斥频带。
2. 代数上 `D'=L+(1+aM)M+(1+aH)H`；两个细节系数均在 `[.75,1.25]`，L 没有单独门控。
   空间变化的门控仍可产生频谱混合，因此不宣称“输出低频严格不变”。
3. 有逐点界 `|D'-D| <= .25*(|M|+|H|)`。由于不同成分可相消，这不是相对于 `|D|` 的 25% 界，
   也不能保证训练后的召回率或全网梯度不下降。
4. 最后一个 1×1 投影零初始化，因此起点严格 `Y=Concat(S,D)`。创建新卷积时隔离 CPU RNG，
   使同 seed 的父级 P2 后续层参数逐张量一致；首步新投影有梯度，context 分支开始梯度为零，
   投影打开后才有梯度，这是零残差初始化的预期性质。
5. 恒等起点与相同初始化不保证后续训练轨迹相同；不同算子或运行环境仍可引入差异。
6. 不改标签分配、不加背景损失、不加风格增强，先单独考察该模块。

实现：`firesmoke/band_refinement.py`；注册：`firesmoke/models.py`。
只用 PyTorch 内置卷积、池化和逐点运算，没有额外扩展依赖。

## 4. 已实现消融

| method | 门控输入 | 修正对象 | 研究问题 |
|---|---|---|---|
| p2 | 无 | 无 | 已有配对父级 |
| p2_srdg | S | 整个 D | 已归档候选参考 |
| p2_dcbr | S、L、E | M、H 分别调制 | 新候选完整机制 |
| p2_dcbr_semantic | S，局部输入置零 | M、H 分别调制 | 局部证据是否必要 |
| p2_dcbr_whole | S、L、E | 两个分支都改为 D/2 | 分带调制是否必要 |

后两个对照和完整版本拥有同样的参数形状和计数。`semantic` 的零输入使部分权重不起作用，
所以是**输入信息消融**，并非完全相同有效容量。`whole` 仍用分带能量作为门控条件，
只消融“被调制对象”，不能将它描述成“完全移除频率分解”。采用 D/2 避免两个分支直接相加
把整特征调制幅度加倍。所有 ablation 从相同零投影起点开始。

这两个内部消融不能代替外部方法比较。进入正式论文前仍需要在同协议下引入
FreqSelect/FreqFusion 或适配 DySample 等最接近方法；本轮没有冒充已复现这些方法。

## 5. 成本与验证

CPU、torch 2.11.0+cu130、Ultralytics 8.4.42；同一 `get_flops`/THOP 口径估算：

| 模型 | 参数量 | GFLOPs@640（工具估计） |
|---|---:|---:|
| P2 | 2,638,312 | 10.1378304 |
| P2+SRDG | 2,642,472 | 10.3475456 |
| P2+DCBR / 两个消融 | 2,641,832 | 10.3221504 |

DCBR 增加 3,520 参数（约 .133%），估算计算量增加 .18432 GFLOPs（约 1.82%）。
THOP 对 tanh、abs、拼接、广播等操作覆盖有限，这不是完整算子成本，也不能推出 GPU 延迟。
同硬件、batch、精度和测量条件下的 latency/p95/显存仍未测量；应在训练后使用 benchmark。

本轮实测：所有版本可在 CPU 上以 640×640 前向，输出 `[1,6,34000]` 且有限；
共有 378 个张量、2,171,791 个元素按相同策略迁移。
测试覆盖：恒等起点、父级逐层参数和预测一致、分解重建、常量边界、修正幅度界、非零/有限梯度、
消融隔离、权重保存加载、YOLO checkpoint 加载与 fuse、空目标损失、预检阻断和默认不训练。
详见 [VALIDATION.md](VALIDATION.md)。GPU 训练、AMP、ONNX/TensorRT 导出不在此次验证范围。

## 6. 你来执行的训练

使用单独的 `configs/protocol-dcbr.yaml`（沿用 v2 schema），v1/v2 旧配置和旧结果不变。
启动器按 seed 匹配 `experiments/yolo11n/D-Fire_p2_seed{seed}/run.json`，检查训练超参、初始化、
选择准则、数据 portable 指纹/数量/类别/标签策略、预训练 SHA256、P2 图 SHA256。
缺少父级证据就报错；不会把两个缺失指纹判断为相同。

```bash
conda activate yolo11
# 仓库根目录；默认及 --dry-run 都仅预检
python scripts/train_dcbr.py --seed 0 --dry-run

# 由研究者主动运行。该命令才启动训练
python scripts/train_dcbr.py --seed 0 --execute
```

固定 100 epochs、640、batch32、SGD、lr .01、AMP=false；checkpoint 选 val mAP50-95。
不从 SRDG 或 P2 best.pt 续训，仍只迁移原始 YOLO11n 的共享层。
默认原始输出：`outputs/module-dcbr-v1/dfire/p2_dcbr/seed0/`。
成功后归档：`experiments/yolo11n/D-Fire_p2_dcbr_seed0_module-dcbr-v1/`。
归档名包含 tag，重试必须换 `--tag`；不自动覆盖/续训。`--no-archive` 可取消副本。

本地预检的数据、权重与配对协议均通过；工具环境 CUDA 不可用，预检 exit=1 正确阻断。
在实际 GPU 训练终端重新执行预检；不要仅为通过检查更改固定训练协议。

seed0 完成并按下面规则判读后，研究者可执行：

```bash
python scripts/train_dcbr.py --seed 1 --execute
python scripts/train_dcbr.py --seed 2 --execute
python scripts/train_dcbr.py --method p2_dcbr_semantic --seed 0 --execute
python scripts/train_dcbr.py --method p2_dcbr_whole --seed 0 --execute
```

有机制收益后对保留消融补齐 1、2；不同时更换增益、epochs 和增强。
为直接对比 SRDG 三种子，仍需另一工作站补齐其 seed1/2；单 seed SRDG 仅用作动机。

## 7. 训练前固定的判定规则

1. **筛查**：seed0 有限损失、有效 checkpoint，重评源域 val 的 best.pt。若 mAP50-95 较同 seed
   P2 下降超过 .003（0.3 个百分点），先检查失败案例与门控分布，不自动投入所有种子。
   这是工程筛查阈值，不是显著性检验；负结果保留。
2. **主要终点**：三 seed 配对 AP50-95 平均变化；目标至少 +.003，至少两个 seed 同向，逐值
   和均值±样本标准差全部报告。该目标也不是统计显著性的替代品，3 seed 对不确定性的刻画有限。
3. **召回约束**：按现有 reliability 工具分别在源域 val 校准每类 1% 经验负例 FPR 预算，
   固定各模型阈值后比较 fire/smoke 图像级 recall，工程容忍下降上限 1 个百分点。
   同时报背景图 alarm fraction、FP/image；“每类 FPR 1%”不等于联合背景报警率 1%。
   校准集与设计选择共用 val，结果有选择偏差，最终泛化结论只来自冻结后的 test。
4. **机制**：两项消融分别验证局部条件与分带作用。`module.diagnostics(x)` 可在显式验证特征
   probe 时返回 gate 饱和比例、各成分 RMS、修正相对幅度；正常 forward 不保留激活或写日志。
   按 TP、小目标 FN、背景 FP 分组采样（先固定采样规则），不能用整图 gate 均值代替检测指标。
5. **小目标贡献**：需要实现/验证尺寸分层评估后才可提出该主张。预定主口径为原图框面积的
   COCO 32²/96² 分界，同时另报缩放到 640 letterbox 后的目标像素尺寸分布；两种口径不得混称。
   当前仓库整体 AP 不等于已经支持 AP-small，不能删除大框标签后将它们当背景来计算小目标 AP。
6. **外部有效性**：完成源域选择后固定结构、checkpoint 和阈值，评估 D-Fire test 与
   FASDD_CV zero-shot；若只完成 D-Fire 训练，只能报告这个方向，不能写成双向跨域。
7. **效率**：相同设备/精度下测延迟和显存；参考工程预算为相对 P2 延迟不增加超过 10%。
   不同电脑训练总时长不用于这一判定。
8. **停止规则**：若完整版本与 whole/semantic 差异不稳定，不写“分频带/局部条件机制成立”；
   若只在调整阈值后改善一个工作点，不写“总体检测能力提升”。不根据 test 结果反复设计模块。

## 8. 可复现性与论文边界

保留 SRDG 阴性/中性结果，有助于说明为什么选择该研究假设；不能删除它来制造单调提升表。
prepared portable 指纹覆盖清单与标签，但现有 metadata 的 `image_content_hashed=false`，
不能声称已核对所有图像字节或已排除近重复泄漏。正式论文仍需完成既有 audit 流程。
新代码源指纹由 provenance 记录（包括 `band_refinement.py` 和所有配置）；训练环境版本也应记录。

DCBR 和 FADC 的 FreqSelect 在频带重加权上接近；联合语义/细节条件、粗成分直通、受限残差
与 P2 成对初始化是此次设计选择，不能直接升级成“首次发现”或“四项独立创新”。
达到更高水平论文需要靠机制证据、可靠性与跨域实验以及对最接近方法的受控比较。
